{% chapter { label: "Behind the scenes", title: "Keeping a dense evidence report calm." } %}

InterSecLab's analysis of Russia's state-mandated messenger runs to 83 numbered pages of findings, footnotes and tables. I set it on a four-column A4 grid with a 15&nbsp;pt baseline, so every text frame, figure and table lands on the same lines, whatever the page carries.

{% chapter { label: "Translations", title: "One grid, three alphabets." } %}

The report was also published in Russian and Ukrainian, on the same grid and styles. Cyrillic runs longer than English, so the layouts had to flex: the Russian edition grows from 90 to 99 pages and the Ukrainian to 96.

Scroll each row to compare the editions page for page.
